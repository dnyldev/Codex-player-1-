چه چیزی زیر کاپوت است

بدون فریم‌ورک، بدون تصویر بیرونی، بدون ردی از کتابخانه. فقط HTML، CSS و کمی جاوااسکریپتِ خوانا.

جعبه‌ی CSS · ویژگی‌های منطقی برای RTL
.card {
  padding-inline: var(--pad);
  margin-block-start: 1rem;
  border-inline-end: 1px solid var(--line);
}

/* logical properties: no left/right anywhere */
.tabs[aria-selected="true"] {
  background: var(--brand);
}

به‌جای left/right از inline/block استفاده شده؛ همین یک تصمیم باعث می‌شود کل صفحه با dir="rtl" بدون هیچ استثنایی آینه شود.
